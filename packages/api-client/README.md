# @pishkhan/api-client

> ⚠️ **هشدار امنیتی و معماری:**
> محتویات پوشه `src/generated` به صورت خودکار توسط دستور `pnpm generate:client` از فایل `openapi.json` تولید می‌شود.
> **هرگز کدهای داخل `src/generated` را به صورت دستی ویرایش نکنید.**
> هرگونه تغییر در قرارداد API باید ابتدا در بک‌اند اعمال شود، سپس `php artisan scramble:export` و بعد `pnpm generate:client` اجرا شود.
> در خط لوله CI اسکریپت `contract-check.sh` عدم تغییر دستی و همگام بودن کلاینت را تضمین می‌کند.
